# DT224G - Laboration 4

Detta är/var en skoluppgift med syftet att:
> * Förstå hur JavaScript kan användas för att lösa enklare programmeringsproblem.
> * Använda Node.js och en utvecklingsmiljö för att skriva, köra, testa och felsöka JavaScript-kod.
> * Tillämpa grundläggande programmeringskoncept som variabler, datatyper, operatorer, villkor och loopar.
> * Använda arrayer och objekt för att lagra och hantera flera värden.
> * Skapa och använda funktioner samt förstå begreppen parameter, argument och returvärde.
> * Strukturera programkod på ett tydligt och läsbart sätt.
> * Använda Git för att versionshantera programkod och dokumentera arbetet genom regelbundna commits.
